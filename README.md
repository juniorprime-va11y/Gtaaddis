# GTA Addis: Southside Stories

Browser-based 3D open-world crime drama set in Addis Ababa, Ethiopia.

**Current milestone:** M1 — Compact Piazza vertical slice (foundation stage).

## Requirements
- Node.js 18+
- Modern browser with WebGL

## Setup
```bash
npm install
npm run dev
```

## Scripts
- `npm run dev` — development server
- `npm run build` — production build
- `npm run typecheck` — TypeScript check
- `npm test` — unit tests (Vitest)

## Controls (foundation)
Camera currently orbits for demonstration. Player controls will be added in subsequent stages.
